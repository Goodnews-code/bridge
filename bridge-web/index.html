Install

Load unpacked once. Pin Bridge. Pay in Naira on the next dollar checkout.

  1. Download and unzip. Confirm you see manifest.json.
  2. Open chrome://extensions → turn on Developer mode.
  3. Click Load unpacked → select the bridge-extension folder.
  4. Pin Bridge → open the demo checkout → Pay in Naira.

Bridge

Pay dollar checkouts in Naira. No Grey. No virtual dollar card. Install the extension, open a foreign payment page, click Pay in Naira.

Chrome will not let a website silently install an extension. Anyone can download the zip and load it in 30 seconds, or we publish later on the Chrome Web Store (Google review, not instant).

Install on Chrome (hackathon / teammates)

  1. Download the zip and unzip it. You should see manifest.json inside the folder.
  2. Open chrome://extensions.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the unzipped nairadirect-extension folder.
  5. Pin Bridge. Open the demo checkout — the overlay should appear.

What this prototype does

  • Detects USD / EUR / GBP checkout pages.
  • Quotes Naira using a live FX rate plus 1.5% fee.
  • Opens a Wema-style Naira checkout (demo NUBAN + pipeline).
  • Does not inject card numbers into Stripe. Does not issue a user virtual card.

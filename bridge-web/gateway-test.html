Test on Stripe

Use a real Stripe Checkout or Payment Link. Bridge detects hosted pages like checkout.stripe.com and buy.stripe.com.

Setup (5 minutes)

  1. Create a free Stripe account → turn on Test mode.
  2. Products → Add product (e.g. “Northwind Pro”) at $12.99 USD.
  3. Payment links → Create link → copy the URL (https://buy.stripe.com/...).
  4. Start Bridge backend: cd bridge-backend && npm run dev.
  5. Chrome → chrome://extensions → Reload Bridge (0.2.2).
  6. Open your Payment Link. Wait 1–2 seconds. The Pay in Naira overlay should appear.

Test card (Stripe test mode)

Card 4242 4242 4242 4242, any future expiry, any CVC. You do not need to complete the Stripe pay if Bridge overlay already showed — for the demo click Pay in Naira instead.

If nothing shows

  1. Confirm Bridge is enabled in the popup.
  2. Confirm backend health: http://localhost:4000/health.
  3. Hard refresh the Stripe page. Amount must be visible as text (e.g. $12.99).
  4. Embedded Stripe iframes on a merchant site may hide the amount — use a Payment Link or Checkout hosted URL instead.
